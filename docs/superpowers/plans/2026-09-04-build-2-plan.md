# greplost build 2: languages, IaC, signals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend greplost from TypeScript/TSX/JS/JSX/Go to Python, Rust, Java, Kotlin, Terraform, Kubernetes and Helm YAML, GitHub Actions and Dockerfiles, add a framework signal layer (React, TanStack Start, Next.js, Pulumi in TypeScript and Go), make non-file nodes first-class in the map and the CLI, and gate every addition against a compiler-grade truth generator on a pinned corpus.

**Architecture:** One extraction module, one resolution module, one reference module, one fixture and one independent truth generator per language or format, all reached through dispatch tables and a convention-based truth registry that leaf 2.0 writes up front, so no two leaves ever edit the same file. Framework signals are a second pass over the same parse tree, contributing extra `Declaration`s and `ReferenceRecord`s without touching what the language extractor produced. Non-file nodes live in `graph/symbols.jsonl` (never in the manifest) and get their own cards under a directory named after their file, so no artifact path contains a `#`.

**Tech Stack:** Bun 1.2, TypeScript strict with `verbatimModuleSyntax`, `web-tree-sitter` 0.27 with vendored WASM grammars, `bun test`. Truth generators: python3 3.14 (`ast`), cargo/rustc 1.88 (`syn`, `cargo metadata`), javac 21 (Compiler Tree API), Go (`terraform-config-inspect`, `go/types`), `js-yaml` 4, `dockerfile-ast`, the TypeScript compiler API, helm and kubectl.

**Spec:** `docs/superpowers/specs/2026-09-04-languages-iac-signals-design.md`

## Global Constraints

- Bun for everything: `bun test`, `bun run`, `bunx`. Never `npm`/`npx`/`node` for project scripts.
- Node-compatible APIs only inside `packages/**` (`node:fs`, `node:path`, `node:crypto`); `Bun.*` globals are allowed only under `bench/`.
- TypeScript strict, `verbatimModuleSyntax`: `import type` for types, explicit `.ts` extensions on relative imports.
- `packages/core/src/schema.ts` is driver-owned. Only task 0 may edit it, and only with the amendments listed in spec section 0.1.
- Determinism: `compareStrings`/`compareEdges`/`compareDeclarations` for every sort, `stableStringify` for every JSON, no `Date`, absolute paths, hostnames or environment values in structure-layer output.
- Never name a function or variable `declare` (Bun's transpiler drops top-level `declare(...)` calls); use `declareX`.
- Node id for a non-file node is `` `${file}#${kind}.${name}` `` via `nodeId()`. No artifact path ever contains `#`.
- Reference confidence: `high` for a unique resolution, `med` for exactly one documented hop, otherwise the edge is **dropped**. Never guess.
- Every gate must fail red before its implementation starts.
- Dependencies are pre-declared in package manifests by task 0. No later task adds a package.
- Grammar versions are pinned exactly: tree-sitter-python 0.25.0, tree-sitter-rust 0.24.0, tree-sitter-java 0.23.5, tree-sitter-kotlin 0.3.8, tree-sitter-yaml 0.5.0, tree-sitter-hcl v1.2.0 (`fad991865fee927dd1de5e172fb3f08ac674d914`), tree-sitter-dockerfile v0.2.0 (`868e44ce378deb68aac902a9db68ff82d2299dd0`). `web-tree-sitter` 0.27 accepts ABI 13 to 15.
- Corpus commits are pinned in spec section 5.1 and are written once, by task 0. No later task edits `bench/corpus.json`.
- Head-to-head (X1 to X10) is untouched: no competitor is run on a build-2 language. `RESULTS.md` says so.

```ts
// packages/core/src/lang.ts
import { DOCKERFILE_PREFIX, LANG_BY_BASENAME, LANG_BY_EXTENSION } from "./schema.ts";
import type { Lang } from "./schema.ts";

/**
 * The language of a repo-relative path, or undefined when greplost has no extractor for it.
 * Basename rules run first so `Dockerfile.dev` is a Dockerfile and not an unknown ".dev" file.
 */
export function langOf(path: string): Lang | undefined {
  const slash = path.lastIndexOf("/");
  const base = slash === -1 ? path : path.slice(slash + 1);
  const byBasename = LANG_BY_BASENAME[base];
  if (byBasename !== undefined) return byBasename;
  if (base.startsWith(DOCKERFILE_PREFIX) && base.length > DOCKERFILE_PREFIX.length) return "dockerfile";
  const dot = base.lastIndexOf(".");
  if (dot <= 0) return undefined;
  return LANG_BY_EXTENSION[base.slice(dot)];
}
```

```ts
export function nodeId(file: string, kind: DeclKind, name: string): string {
  if (name.includes("#") || name.includes("\n") || name.includes("\0")) {
    throw new Error(`greplost: node name may not contain "#", a newline or NUL: ${JSON.stringify(name)}`);
  }
  return `${file}#${kind}.${name}`;
}

export function splitNodeId(id: string): { file: string; kind: DeclKind; name: string } | null {
  const hash = id.indexOf("#");
  if (hash <= 0) return null;
  const rest = id.slice(hash + 1);
  const dot = rest.indexOf(".");
  if (dot <= 0) return null;
  const kind = rest.slice(0, dot) as DeclKind;
  if (!NODE_KINDS.has(kind)) return null;
  return { file: id.slice(0, hash), kind, name: rest.slice(dot + 1) };
}
```

- [ ] **Step 11: Write the signal-pass registry**

```ts
// packages/core/src/signals/index.ts
import { compareDeclarations, compareStrings } from "../schema.ts";
import type { Declaration, FileRecord, Lang, ReferenceRecord } from "../schema.ts";
import type { Tree } from "web-tree-sitter";
import { reactPass } from "./react.ts";
import { tanstackPass } from "./tanstack.ts";
import { nextPass } from "./next.ts";
import { pulumiTsPass } from "./pulumi-ts.ts";
import { pulumiGoPass } from "./pulumi-go.ts";

export interface SignalInput {
  path: string;
  lang: Lang;
  source: string;
  tree: Tree;
  base: Readonly<Pick<FileRecord, "decls" | "imports" | "exports" | "calls">>;
}
export interface SignalOutput { decls: Declaration[]; refs: ReferenceRecord[] }
export interface SignalPass {
  readonly id: "next" | "pulumi-go" | "pulumi-ts" | "react" | "tanstack";
  readonly langs: ReadonlySet<Lang>;
  applies(path: string, source: string): boolean;
  run(input: SignalInput): SignalOutput;
}

/** Sorted by id so the pass order is part of the determinism contract. */
export const SIGNAL_PASSES: readonly SignalPass[] = [
  nextPass, pulumiGoPass, pulumiTsPass, reactPass, tanstackPass,
].sort((a, b) => compareStrings(a.id, b.id));

export function runSignals(input: SignalInput): SignalOutput {
  const decls: Declaration[] = [];
  const refs: ReferenceRecord[] = [];
  for (const pass of SIGNAL_PASSES) {
    if (!pass.langs.has(input.lang)) continue;
    if (!pass.applies(input.path, input.source)) continue;
    const out = pass.run(input);
    decls.push(...out.decls);
    refs.push(...out.refs);
  }
  decls.sort(compareDeclarations);
  refs.sort(
    (a, b) =>
      compareStrings(a.from, b.from) ||
      compareStrings(a.to, b.to) ||
      compareStrings(a.refKind, b.refKind) ||
      a.line - b.line,
  );
  return { decls, refs };
}
```

Every pass module is stubbed as `{ id, langs, applies: () => false, run: () => ({ decls: [], refs: [] }) }`
so the layer is inert until its leaf lands.

```ts
const CONST_NAME = /^[A-Z][A-Z0-9_]*$/;

function collectModule(state: PyState, root: Node): void {
  for (const node of root.namedChildren) {
    switch (node.type) {
      case "function_definition":
        addFunction(state, node, null);
        break;
      case "class_definition":
        addClass(state, node);
        break;
      case "decorated_definition":
        addDecorated(state, node);
        break;
      case "expression_statement":
        addAssignment(state, node);
        break;
      default:
        break;
    }
  }
}

function addFunction(state: PyState, node: Node, parent: string | null): void {
  const name = node.childForFieldName("name")?.text ?? "";
  if (name === "") return;
  const path = parent === null ? name : `${parent}.${name}`;
  const body = node.childForFieldName("body");
  const header = state.source.slice(node.startIndex, body === null ? node.endIndex : body.startIndex);
  addDeclaration(state, {
    name: path,
    kind: parent === null ? "function" : "method",
    signature: collapse(header.replace(/:\s*$/, "")),
    exported: exportedName(state, name),
    span: [node.startPosition.row + 1, node.endPosition.row + 1],
    ...(parent === null ? {} : { parent }),
  });
}
```

```ts
// packages/render/src/slug.ts
export function nodeSlug(kind: DeclKind, name: string): string {
  return `${kind}.${name}`.replace(/\//g, "__").replace(/[^A-Za-z0-9._-]/g, "-");
}

export function nodeCardPath(pkg: PackageInfo, id: string): string {
  const parts = splitNodeId(id);
  if (parts === null) throw new Error(`greplost: not a node id: ${id}`);
  const rel = pkg.path === "." ? parts.file : stripPackagePrefix(parts.file, pkg.path);
  return `${packageDir(pkg.name)}/modules/${rel}/${nodeSlug(parts.kind, parts.name)}.md`;
}
```
