# Sub-project spec: render

Implements tech spec sections 4.2, 4.3, 5.3 (Mermaid ordering) and metrics M1, M2. Package: `packages/render` (`@greplost/render`).
Consumes `Snapshot` and `SummaryCache` from `@greplost/core/schema`. Pure: no filesystem access, no dates except inside the semantic banner text passed in.

## Interfaces

```ts
// mermaid.ts
export interface GraphNode { id: string; label: string; }
export interface GraphEdge { from: string; to: string; label?: string; }
export interface GraphSpec { direction: "LR" | "TD"; nodes: GraphNode[]; edges: GraphEdge[]; }
export function mermaidId(raw: string, taken?: Set<string>): string;   // [^A-Za-z0-9_] -> "_"; prefix "n_" when empty or starting with a digit; collisions get "_2", "_3" in call order
export function renderGraph(spec: GraphSpec): string;                   // "```mermaid\ngraph LR\n  id[\"label\"]\n  a --> b\n  a -->|3| b\n```" ; nodes and edges emitted in sorted order; labels escape " as #quot;
// ascii.ts
export function renderTree(paths: string[], opts?: { annotate?: (path: string) => string }): string;   // box-drawing tree, directories before files, code-unit sorted; annotation appended after two spaces
// split.ts
export interface SplitNode extends GraphNode { dir: string; }          // dir = path segments relative to the diagram root, joined by "/"
export interface Diagram { title: string; spec: GraphSpec; }
export function splitDiagram(root: string, nodes: SplitNode[], edges: GraphEdge[], maxNodes: number): Diagram[];
// tokens.ts
export const INDEX_TOKEN_BUDGET = 3000;
export function estimateTokens(text: string): number;                  // Math.ceil(text.length / 3.5)
// slug.ts
export function packageDir(pkgName: string): string;                   // `packages/${packageSlug(pkgName)}`
export function cardPath(pkg: PackageInfo, file: string): string;      // `${packageDir}/modules/${relative-to-package-path}.md`; root package uses the full path
export function relLink(fromArtifact: string, toArtifact: string): string;   // posix relative link between two artifact paths
// render.ts
export interface RenderInput { snapshot: Snapshot; summaries: SummaryCache; }
export function renderArtifacts(input: RenderInput): Map<string, string>;   // every markdown artifact, keyed by path relative to .greplost/
```

## Rules

**Mermaid.** Only `graph LR|TD` in v1. Node ids come from `mermaidId(raw)` where `raw` is the node id from the snapshot (file path, package name); ids are assigned in sorted `raw` order so a new node never renumbers others. Labels are the display names (`packages/core/src/registry.ts` → `registry.ts` inside a package diagram, full package name in the container view). Edge labels carry counts when > 1. Every diagram ends with a blank line after the fence.

**Auto-split.** `splitDiagram` returns one diagram when `nodes.length <= maxNodes`. Otherwise it groups nodes by the first segment of `dir` (files directly under the root form the group `"."`): the first diagram, titled `<root> (overview)`, has one node per group labelled `<group>/ (<n> files)` (a `"."` group keeps its individual files if that stays within the cap, else becomes a `./ (<n> files)` node) and aggregated edges with counts; then one diagram per group, recursively split with the group as the new root. A group that is a single flat directory with more than `maxNodes` files is paginated: chunks of `maxNodes` in sorted order, titled `<dir> (part i of n)`, containing only intra-chunk edges. Postcondition asserted in tests: every returned diagram has `<= maxNodes` nodes.

**Token budget.** `renderIndex` must return text with `estimateTokens(text) <= INDEX_TOKEN_BUDGET` for any input. Degradation order: (1) cut the package table to the top K packages by LOC, K from all down to 10, appending `… and N more packages, see repo/MAP.md`; (2) limit the tree to depth 2 (then depth 1, then drop it) and re-maximise K against the smaller tree; (3) drop the hotspot lists and re-maximise K again. The largest K that fits is always used (ruling 2026-09-02). Tests cover 5, 60 and 500 synthetic packages.

## Documents

Common header rule: every artifact starts with a level-1 title and the line
`> Generated by greplost. Do not edit by hand; run \`greplost update\`.` (INDEX.md carries the longer agent-facing version below). No timestamps anywhere.

GitHub rendering rule (ruling 2026-09-02): repository Markdown treats a single newline as a space, so every field line of a card is its own paragraph (blank line between fields, blank line before `**Calls:**`, blank line between the summary blockquote and the stale banner blockquote); path templates such as `packages/<pkg>/MAP.md` are always inside backticks (bare `<pkg>` is stripped as an unknown HTML tag); packages with zero indexed files keep their INDEX table row but are omitted from the ASCII package tree and the container diagram; `renderArtifacts` throws when two package names slug to the same directory.

Summary line: `summaries[sha256].text` when present; else when `staleSummary` the text of `summaries[summaryHash]` plus the banner; else `No summary yet; run \`greplost refresh\`.`. Export entries: functions and callable consts show `name(params): ret` derived from the signature by stripping `export`, `default`, `declare`, `async`, `function`, and the `const name =` prefix for arrow functions; everything else shows `name (kind)`. Imports list groups by specifier in source order of first appearance, symbols sorted. Key symbols: every declaration in line order, signature stripped of `export`/`declare`; more than 50 → first 50 and `- … <n> more`.

## Golden test

`packages/render/test/golden/tiny-ts/**` holds the full render of the fixture's snapshot (built through `buildSnapshot` on `fixtures/tiny-ts` with an empty summary cache and one seeded fresh summary for `packages/core/src/retry.ts` and one stale summary for `packages/core/src/bus.ts` to exercise the banner). The test renders and compares every file byte for byte; `GREPLOST_UPDATE_GOLDEN=1` rewrites. Also asserted: every mermaid fence in every artifact has `<= 25` nodes; `estimateTokens(INDEX.md) <= 3000`; rendering the same input twice yields identical maps; no artifact contains an absolute path or the string `20` followed by a digit pair and a hyphen in a date shape outside the stale banner.
