# Sub-project spec: go

Implements Go support (tech spec 5.1 language table, M5) in core and the Go truth generator in bench. Leaf 1.8 owns: `packages/core/src/extract/go.ts`, `packages/core/src/resolve/go.ts`, the Go dispatch lines in `packages/core/src/extract/index.ts` and `packages/core/src/resolve/resolver.ts` (edits limited to adding the `go` branch), `packages/core/test/extract-go.test.ts`, `bench/src/truth/go.ts`, `bench/test/truth-go.test.ts`, `fixtures/tiny-go/**`.

## Extraction (extract/go.ts)

Grammar `tree-sitter-go.wasm` (vendored). Per file:

- Declarations: `function_declaration` → `function`; `method_declaration` → `method`, name `<ReceiverType>.<name>` (pointer star stripped), `parent: <ReceiverType>`; `type_declaration` specs → `struct` for struct types, `interface` for interface types, `type` otherwise; `const_declaration`/`var_declaration` specs → `const`/`var` (one per identifier). `exported` = first rune is upper case. Signature = header text up to the body `{` (whole spec for types without a body), whitespace collapsed, 200-char cap.
- Imports: every `import_spec`: specifier = import path; `kind: "static"`; symbols `[{ name: "*", local: <alias or last path segment> }]`; alias `_` → `side-effect` with symbols `[]`; alias `.` → local `"."`.
- Exports: one `named` record per exported declaration.
- Call sites: `call_expression` with `identifier` → `name`; `selector_expression` with identifier operand → `obj.field`; receiver calls on a method's receiver variable are `obj.m` where `obj` is the receiver name (resolved below as `this.m`); composite literals are not calls.

## Resolution (resolve/go.ts)

- Module path: nearest `go.mod` upward from the importing file (`module <path>` line); repo may contain several (go.work). Import path `P`: if `P` equals a module path `M` or starts with `M + "/"`: target dir = module dir + remainder; if that directory contains any indexed `.go` file → `{ type: "file", path: <dir> }` (a **directory id**, since Go imports packages; the card layer treats it as a file id and the "importers" list of every `.go` file in the directory includes the importer). Otherwise standard library and external module paths → `{ type: "external", pkg: P }`.
- Call resolution additions in `linkCalls` (implemented inside `resolve/go.ts` as a helper the linker calls for `lang === "go"` files): `name` → a declaration `name` in any indexed `.go` file of the same directory → `high`; `obj.m` where `obj` is an import alias → the declaration `m` in any file of the target directory → `high`; `obj.m` where `obj` is the receiver variable name of the enclosing method → `<file>#<Type>.m` in the same directory → `high`; otherwise drop.

## Truth (bench/src/truth/go.ts)

`generateGoTruth(root, files)`: imports via `go list -json -deps ./...` (package → directory edges mapped to `(file, dir)` per importing file using each package's `GoFiles`/`Imports` plus per-file import parsing from `go list -json` `CompiledGoFiles` when needed); calls via `golang.org/x/tools/go/callgraph/cha` through a small Go program vendored at `bench/truth/gocallgraph/main.go` (built once with `go build`, cached under `bench/.corpus/.tools/`); exports via `go doc`-free parsing of `go list -json` `Export` is not sufficient, so use the same Go program to print exported identifiers per file. Output in the shared `Truth` shape with directory ids for import targets.

## Fixture

`fixtures/tiny-go/` = one module `example.com/tiny` with `go.mod`, packages `cmd/app/main.go` (imports `example.com/tiny/internal/store` and `example.com/tiny/internal/retry`, calls `store.New`, `retry.Do`), `internal/store/store.go` (`type Store struct`, `func New() *Store`, `func (s *Store) Put`), `internal/store/memory.go` (calls `New` from the same package), `internal/retry/retry.go` (`func Do`, `const DefaultAttempts`), one `_test.go` that must be excluded. 6 files, 5 indexed.
