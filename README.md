# greplost

> grep lost. Read the map.

greplost is not a search tool. It is the map you read so you don't have to search.

It generates a committed, deterministic, always-fresh map of a codebase (Markdown, ASCII trees, Mermaid diagrams) under `.greplost/`, built from the AST with no LLM in the loop, verified in CI, and readable by humans and coding agents alike.

Status: under construction. Design: [docs/greplost-tech-spec.md](docs/greplost-tech-spec.md). Benchmarks land in `bench/RESULTS.md` and are never filled in by hand.
